Taste profiles

One small JSON file pins how your product looks. Agents read it before every change and leave the locked parts alone.

Create a profile

Run the installer once. It writes taste-profile.json next to your package.json and copies only the tokens you picked.

Profiles are deterministic

The same choices always produce the same bytes, so profiles diff cleanly in code review.

Lock what matters

Locked axes survive every follow-up edit. Ask an agent to “make it darker” and only the unlocked axes move. Press ⌘K and search “locks” to jump here.

Colour overrides are checked

An override that breaks contrast is rejected by the installer with the failing pair named.

Attach to an existing app

Set installMode to attach. Tokens then apply only inside .lt-root, and every base style has zero specificity, so your host styles always win.
