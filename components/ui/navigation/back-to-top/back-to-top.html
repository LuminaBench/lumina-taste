Dashboard guidelines

Every chart on the overview reads from the same filter bar, so changing the date range changes every card together.

Cards keep their own loading state. A slow query never blanks the whole page; it shows a skeleton where its numbers will go.

Numbers use tabular figures and right alignment so columns line up when values change.

Colour is reserved for meaning. Series keep their colour when filters change, so a line never swaps identity.

Each card has one job. If a card needs a paragraph to explain it, it is two cards.

Exports live in one menu at the top, never as buttons on every card.

Empty states say why there is nothing and offer one way forward.
