The header slides away as you read down

Scrolling down hides the header so the text gets the full height. Scrolling up even a little brings it straight back, because that is when readers want to navigate.

The threshold ignores tiny trackpad jitters, and the header never hides while a menu inside it has focus.

Under reduced motion it still hides and shows, just without the slide.

Pair it with scroll-padding-top so anchor links never land underneath the header.

Keep the header 56px tall or less on mobile.
