From database to dashboard in an afternoon

  1. 1

    Connect your database

    Paste a read-only connection string. Halyard reads the schema, never the rows, until you ask for a chart.

  2. 2

    Pick the numbers that matter

    Choose from the measures it finds, or write one in SQL. Each gets a name, a unit and an owner.

  3. 3

    Share one link

    Everyone sees the same figures, updated every hour. Set an alert and the page tells you when one moves.
