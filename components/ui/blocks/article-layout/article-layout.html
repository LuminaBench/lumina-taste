Define a metric once, use it everywhere

When three dashboards disagree about revenue, the problem is rarely the chart. It is the definition.

Why one model

A metric model holds the query, the filters and the name in one place. Every chart that uses "Revenue" reads the same definition, so numbers agree by construction.

Change the definition once and every report updates with it.

Define a metric

Start with the question people actually ask. Name the metric the way they say it, then write the smallest query that answers it.
