POST/v1/customers/{id}/invoicesCreate an invoice
Body parameters
NameTypeDescription
amountrequiredintegerTotal in the smallest currency unit, for example 2400 for £24.00.
currencyrequiredstringThree-letter ISO code, lower case.
due_datedateDefaults to 30 days from today.
GET/v1/invoices/{id}Retrieve an invoice
Path parameters
NameTypeDescription
idrequiredstringThe invoice id, starting inv_.
DELETE/v1/invoices/{id}Void an invoice
Path parameters
NameTypeDescription
idrequiredstringOnly open invoices can be voided.
